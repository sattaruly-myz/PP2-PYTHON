# Moving Ball Game

A simple game where you control a red ball using arrow keys.

## How to run
```bash
pip install pygame
python main.py
```

## Controls
| Key        | Action     |
|------------|------------|
| Arrow Keys | Move ball  |
| ESC        | Quit       |

## Rules
- The ball cannot leave the 800×600 screen.
- Each key press moves the ball by 20 pixels.
